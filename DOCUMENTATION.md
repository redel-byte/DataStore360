## UV documentation:

# inisialization of project:

uv init

# install python version and pin it :

uv python install [version] && uv python pin [version]

## install dependencies || remove dependencies:

uv add [dependecie1, dependecie2 ...] || uv remove [dependecie1, dependecie2 ...]

## add .venv

uv sync

## run script:

uv run python script.py
